# Change Log

所有重要的变更都会记录在此文件中。

## [0.1.0] - 2026-05-10

### 新增功能
- ✨ 自动索引工作区
- ✨ 多分支独立索引支持
- ✨ 智能代码搜索（语义搜索、精确匹配、模糊搜索）
- ✨ AI智能问答功能
- ✨ 内联CodeLens显示引用数量和调用关系
- ✨ 交互式调用图可视化
- ✨ 增量索引功能（手动触发）
- ✨ GitLab权限控制和验证
- ✨ 支持TypeScript、JavaScript、Vue文件

### 核心特性
- 🚀 自动检测GitLab默认分支（不再硬编码为main）
- 🚀 共享基础分支索引，节省90%资源
- 🚀 分支差异索引，大幅减少索引时间
- 🚀 手动增量索引，用户自主控制刷新时机
- 🔒 基于GitLab API的权限验证
- 🔒 域名白名单控制
- 🔒 工作区白名单支持

### 支持的语言
- TypeScript (`.ts`, `.tsx`)
- JavaScript (`.js`, `.jsx`)
- Vue (`.vue`)

### 系统要求
- VSCode 1.85.0 或更高版本
- CodeLens API服务器（需单独部署）
- PostgreSQL数据库
- Redis缓存服务
